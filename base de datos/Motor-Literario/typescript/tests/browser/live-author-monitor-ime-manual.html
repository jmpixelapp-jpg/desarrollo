3. Secuencia observada

Se muestran solo metadatos. No se registran letras, candidatos, teclas, valores de data ni fragmentos del documento.

Inicia la captura para comenzar.

4. Secuencia recomendada

  1. Activa el IME del sistema operativo y comienza una composición.
  2. Escribe una forma fonética y cambia entre al menos dos candidatos.
  3. Confirma un candidato y comprueba visualmente el texto final.
  4. Repite otra composición y cancélala con la tecla de cancelación del IME.
  5. Prueba composición junto a texto existente, sustitución de una selección y composición al principio/final del textarea.
  6. Exporta la traza y revisa si hubo pares incompletos, errores o necesidad de resincronización.

La exportación es local: el archivo JSON se descarga desde el navegador. No se envía al servidor. No compartas el texto del textarea; el archivo solo contiene metadatos de eventos.
